# Мессенджер

Мессенджер в стиле Telegram — веб-приложение, которое ставится на телефон как приложение.

Открыть: https://tarasula.github.io/messanger/
На iPhone: Safari → «Поделиться» → «На экран „Домой“».

## Что работает
- Регистрация по почте или через Google, профиль, уникальный @ник
- Поиск людей по @нику, личные чаты и группы в реальном времени
- «Печатает…», «в сети», галочки «прочитано», реакции, ответы, опросы, голосовые, фото
- Удаление у себя и у всех, блокировка, жалобы, удаление аккаунта

Сервер — Firebase (проект `messanger-aab05`). Правила доступа к базе — в файле `firestore.rules`:
их нужно вставить в Firebase → Firestore Database → Rules и нажать Publish.

Звонков между людьми пока нет.
