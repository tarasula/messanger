# Мессенджер

Мессенджер в стиле Telegram — одна веб-страница, которую можно установить на телефон как приложение.

Открыть: https://tarasula.github.io/messanger/

На iPhone: Safari → «Поделиться» → «На экран „Домой“».

Сейчас все чаты хранятся в браузере на устройстве; сервера для переписки между людьми пока нет.
